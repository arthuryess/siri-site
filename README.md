# Command List for Siri – public website

Support and privacy pages for Command List for Siri (Befehlsliste für Siri) on iPhone and iPad.

- Support: https://arthuryess.github.io/siri-site/
- Privacy: https://arthuryess.github.io/siri-site/privacy.html
- Support requests: https://github.com/arthuryess/siri-site/issues

## Publish

GitHub Pages: repository Settings → Pages, Deploy from a branch, main and /(root). No custom domain or build dependencies are required.

## Updates

Edit the HTML/CSS, review both themes on phone and desktop, then commit and push. Keep the effective date accurate when the policy changes, and keep app-store/site in the siri app repository consistent with these published pages. Do not store private app source, keys or user records here.
